# prompt-maker-for-vibecoding
바이브코딩 입문자를 위한 기획 도우미. 질문에 답하면 기획서와 AI 프롬프트가 완성됩니다.
바이브코딩 기획 도우미
바이브코딩이 처음인 사람을 위한 기획·설계 도우미 웹앱입니다. "자, 만들어 봐!"라고 하면 막막하죠. 몇 가지 질문에 답하면 한 장 기획서와 AI에게 그대로 붙여넣을 프롬프트가 완성됩니다.

설치 없음. index.html 파일 하나를 브라우저로 열면 바로 동작합니다.
서버·API 키 없음. 답변은 내 브라우저에만 저장됩니다.
PC와 스마트폰 모두 지원합니다.
이렇게 사용해요
앱 종류 고르기 빙고 게임 · 퀴즈 게임 · 실시간 투표/설문 · 수업 도구(뽑기·타이머) · 나만의 기록장 중 하나를 고르거나, 만들고 싶은 앱을 직접 입력합니다.
질문에 답하기 유형에 맞는 질문(예: 빙고판 크기, 누가 번호를 부르는지)과 공통 질문(사용자, 상황, 기기, 디자인, 사용할 AI 도구)에 하나씩 답합니다. 앞 답변으로 정해지는 질문은 자동으로 건너뜁니다. 오른쪽에 기획서가 실시간으로 채워집니다.
프롬프트 복사하기 완성된 프롬프트를 복사해 Claude, ChatGPT, Gemini, Lovable 등에 붙여넣으면 앱이 만들어집니다. 기본 버전이 나온 뒤 이어서 쓸 수정 요청 프롬프트도 함께 제공합니다.
만들어지는 프롬프트 구조
"앱 이름" 웹앱을 만들어줘.
누가 · 어디서 · 무엇을 하는 앱인지 한 줄 소개
화면 구성:   1) 시작 화면 … 2) 진행자 화면 … 3) 참여자 화면 …
핵심 동작:   - 꼭 되어야 하는 기능
디자인:      - 분위기, 포인트 색, 글씨 크기, 모바일 대응
기술:        - 단일 HTML 파일 / Firebase / Supabase 등 도구에 맞는 요청
먼저 이 기본 버전을 만들어줘. 확인한 뒤 하나씩 추가 요청할게.
선택한 AI 도구에 따라 기술 항목이 달라집니다. Claude·ChatGPT·Gemini는 "index.html 한 파일"과 Firebase 안내가, Lovable은 Supabase 연결 문장이 들어갑니다.

수업에서 활용하기
실습 시작 전에 이 앱으로 각자 기획서를 완성하게 하면, 프롬프트 한 줄로 첫 결과물이 나옵니다.
"고쳐가며 완성하기" 목록은 바이브코딩의 핵심인 만들고 → 보고 → 바꿔달라고 하기 반복을 연습하는 데 쓰입니다.
결과 화면의 파일로 저장 버튼으로 기획서와 프롬프트를 마크다운 파일로 받아 제출용으로 쓸 수 있습니다.
바로 쓰기
